# Getting Started

Three pages take you from nothing to searching your own books with the
`booksmart` CLI:

1. **[Installation](installation.md)**: install the CLI from PyPI and see
   what it keeps on your machine.
2. **[Quickstart](quickstart.md)**: add a public-domain book, run it
   through the pipeline, and search it.
3. **[Configuration](configuration.md)**: choose Providers and models, set
   API keys, and see where each setting comes from.

If you have already installed the CLI, skip to the [Quickstart](quickstart.md).
